Un pez dibujado con dos voltajes

El ESP32 saca dos voltajes que cambian muy rápido, uno para la X y otro para la Y; el osciloscopio en modo XY los usa para mover su punto, y el punto dibuja un pez.

Del modo XY a las figuras de Lissajous

⏚→〰

Un DAC

Convierte un número en voltaje. Los del ESP32 aceptan de 0 a 255: write(0) ≈ 0 V, write(255) ≈ 3,3 V. Solo hay dos: GPIO25 y GPIO26.

✛

El modo XY

Normalmente el osciloscopio dibuja voltaje contra tiempo. En XY el tiempo desaparece: el canal 1 dice qué tan a la derecha va el punto y el canal 2 qué tan arriba.

∞

Lissajous

Si a cada canal le llega una senoidal, el punto traza figuras clásicas (Lissajous, 1857). Nosotros fuimos más allá: el ESP32 calcula la lista de puntos de un pez y la repite sin parar.

Juega con dos senoidales

X = sen(1·t)
Y = sen(1·t + 90°)

Con la misma frecuencia y 90° de desfase sale una elipse: x = cx + rx·cos(t), y = cy + ry·sen(t), que es justo como el script dibuja el cuerpo, el ojo, la pupila y la boca.

El pez, pieza por pieza

En vez de dibujarlo a mano, pez3_esp32.py lo arma con tres formas: elipses, líneas rectas y curvas Bézier. Al arrancar calcula la lista de puntos una sola vez y después solo la recorre en un bucle infinito. Pulsa Armar el pez y mira cómo el haz recorre cada pieza y qué número le llega a cada DAC.

    Cada pieza es una lista de pares (x, y) entre 10 y 245. El bucle principal solo hace
            dac_x.write(x) y dac_y.write(y) con cada par, una y otra vez.

      instálalo con la app del tema 2 ↗.
    

    
    
      
    
        
    
          
    Con osciloscopio
    La demo del laboratorio
    
          
      
            
    1. Conecta el ESP32 por USB y abre en Thonny el script (copia el código de al lado): un pez o tres peces.
      2. 
            
    2. Archivo → Guardar como… → dispositivo MicroPython, con el nombre main.py: así arranca solo al tener energía.
      3. 
            
    3. Cablea como en "Cómo se conecta": GPIO25 → CH1, GPIO26 → CH2, GND → pinzas.
      4. 
            
    4. Osciloscopio en Formato XY, mismos V/div en los dos canales, y centra con la posición vertical.
      5. 
            
    5. Si el pez sale espejado, pon INVERT_X o INVERT_Y = True y vuelve a guardar.
      6. 
          
    
        
    
        
    
          
    Sin osciloscopio
    Ver lo que calcula la placa
    
          
      
            
    1. En el script pon ENVIAR_SERIAL = True (y ESCRIBIR_DAC = False si no hay nada en los pines).
      2. 
            
    2. Córrelo en Thonny con F5: en la Shell salen los puntos como 158 132, 157 135…
      3. 
            
    3. Para verlos dibujados: guárdalo como main.py, cierra Thonny (suelta el puerto), en el simulador pulsa
              Conectado (Web Serial) → Elegir puerto del ESP32 y presiona EN en la placa.
      4. 
            
    4. Antes de la demo real vuelve a ENVIAR_SERIAL = False y ESCRIBIR_DAC = True (imprimir es lento y el pez parpadearía).
      5.
